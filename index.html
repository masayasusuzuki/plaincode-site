ただ、コードを書く。AI導入・システム開発・動画制作・AI研修を、一人で一気通貫。

plaincode は、色のないコーディングをします。流行りの技術やベンダーの流儀ではなく、あなたの課題に最も素直な実装を選び、業務の整理から実装、そして使い方が定着するところまで伴走します。

ai(): Solution

AI導入・業務自動化

社内AIプラットフォームの構想設計から構築まで。日々の作業をAIエージェントやチャットボットに任せ、人がやるべき仕事に時間を戻します。

  • 社内向けAIアシスタント／ナレッジ検索の構築
  • Slack・Discord 常駐エージェント、スプレッドシート×LLM の自動化
  • AIチャットボット・画像診断など既存サービスへのAI機能追加
system(): Software

Webサイト・業務システム開発

企業サイトから管理画面、勤怠・請求、学習プラットフォームまで。フロント・バックエンド・DB・認証・インフラを一人で設計し、本番まで運びます。

  • Next.js / React / TypeScript による高速なWebサイト・LP
  • Supabase・Firebase を使った業務システム・管理画面
  • CMS連携、SEO、Vercel での本番運用まで

  • YouTube・Shorts・広告動画の編集（Premiere Pro / After Effects）
  • 生成AI（画像・動画・音声）を組み込んだ制作
  • 企画・KPI設計から改善提案まで

  • 企業向け 生成AI・Claude Code 活用研修（100名規模の実績）

approach

01

業務を整理する

ツールの話より先に、どこに時間が溶けているかを一緒に見ます。作らない、という結論も普通にあります。

02

素直に実装する

言語・フレームワーク・LLM は「動くか」「分かるか」で選びます。コードは全て納品し、ブラックボックスにしません。

マニュアルと研修まで含めて、担当者が自分で回せる状態にしてから手を離します。

about

plaincode について

Claude Code、Codex、Kimi。AIコーディングツールにはそれぞれの「色」があります。plaincode はその色を全部落として、ただ単純にコードを書くことに向き合うために作った屋号です。

代表の鈴木元康は、マーケティング・動画制作の現場を経てエンジニアになりました。フロントからインフラ、AI統合まで一人で完結させつつ、教える仕事も続けています。
